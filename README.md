## Introduction

This library will show you every 3D print, that we (my organisation) made along our BotBall-journey. It should help you to give you some ideas about how we previously designed parts to complete all sorts of tasks. 

Feel free to send me your 3D prints, so I can add them here as well. Every 3D print is welcomed.

You can also check out my self-made library on [GitHub](https://github.com/J0K3R-Joel/BotBall_Library).

---

## Download

1. Clone the repository: 

```bash
git clone https://github.com/J0K3R-Joel/3D-Print_BotBall_Library.git
```

2. Get into [./prints](./prints) 
3. Open your desired .stl files in your slicer and enjoy the objects

---

## Usage

If you slice the .stl files in your slicer, you will receive a .gcode file. This file is readable for every 3D-printer. Just send the files to the printer and then print it with your settings.
